# Playing Your Map

## Previously...

## Launching Northstar
If you haven't already, [Install Northstar!](../../../Wiki/installing-northstar/basic-setup.md)

!!! note
    At this stage, we're just running your map locally.
    If you want a friend to join you, run a server & give them a copy of your mod.

Once you've made the mod folder, fire up Northstar & it should load the mod automatically
