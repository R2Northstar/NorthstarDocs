## Fundamentals
Every map needs:
 * geometry
   - make a brush
   - `QWER` tools
   - clipping tool
   - vertex tool
 * spawnpoints
   - place point entity
   - spawnpoint types
   - edit keyvalues (set teams & gamemodes)
